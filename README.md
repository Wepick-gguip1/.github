# W-Gain organization defaults

이 저장소는 W-Gain 조직의 공개 프로필과 공통 협업 기본값을 관리합니다.

## Contents

- `profile/README.md`: W-Gain 공개 조직 프로필
- `.github/ISSUE_TEMPLATE/`: 조직 공통 Issue 양식
- `.github/pull_request_template.md`: 조직 공통 Pull Request 양식
- `CONTRIBUTING.md`: 기본 기여 절차
- `GOVERNANCE.md`: 사람과 AI 에이전트의 책임 및 권한 경계
- `SECURITY.md`: 기본 보안 제보 정책
- `SUPPORT.md`: 지원 요청 안내
- `docs/repository-standards.md`: W-Gain 저장소 최소 관리 기준

GitHub는 대상 저장소에 같은 종류의 파일이 없을 때 이 공개 `.github` 저장소의 기본 파일을 적용합니다. 프로젝트별 요구사항이 다르면 해당 저장소의 파일이 이 기본값을 대체합니다.

> `AGENTS.md`는 다른 저장소에 자동 상속되지 않습니다. 각 프로젝트는 자체 `AGENTS.md`를 유지해야 합니다.
